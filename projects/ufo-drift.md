# UFO DRIFT: Space Arcade

**Android · Closed testing**  
An independent game by Parvan Vezenkov, the creator behind Vezen Labs.

![UFO DRIFT promotional artwork](https://vezenlabs.github.io/ufo-drift-banner.jpg)

*Promotional artwork.*

## One finger. Ten cosmic worlds.

The UFO rises automatically. Hold the screen to descend; release to rise. Find your rhythm, avoid futuristic antennas and push your personal best as the pace increases.

## Highlights

- Ten cosmic environments and ten rank milestones.
- Optional lightning and hourglass pickups that temporarily change flight speed.
- Unlockable ships, local best scores and score sharing.
- Optional rewarded Continue to preserve the current score and resume a flight.
- Help, editable feedback emails and privacy controls.

## Design and development

My work spans the gameplay concept, visual direction, interface decisions and iteration through playable Android builds. Testing has informed concrete improvements, including a fix for unexpected pauses at flight startup and removal of the five-second Continue decision timer.

The aim is simple input, readable feedback and a challenge that grows with the player.

## Current status

UFO DRIFT is in closed testing on Google Play. This portfolio does not imply a public production launch. Access is limited to enrolled testers.

This repository contains the project presentation; game source code and signing files are not included.
