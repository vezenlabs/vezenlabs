# PUT IN: Perfect Timing

**Android · In development / device testing**  
An independent game by Parvan Vezenkov, the creator behind Vezen Labs.

## A small action. A big reaction.

A casual timing game built around placing a moving object at just the right moment. Distinct characters and expressive reactions give successful attempts their personality.

## Design focus

- A simple timing challenge with an immediately understandable goal.
- Character-led visuals and expressive success reactions.
- Clear composition: the target object appears once, as the moving gameplay object, rather than being duplicated in the character background.
- Short interactions and iteration through playable Android test builds.

## Development approach

The project brings together gameplay prototyping, character art direction, interface refinement and testing on Android. The focus is on making the timing readable and the feedback satisfying.

## Current status

PUT IN is being developed and tested on devices. It is not yet listed in Google Play Console. Approved gameplay captures and a public store link can be added when ready.

This repository contains the project presentation; game source code and signing files are not included.
